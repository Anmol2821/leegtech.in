FAQ

Trademark classes: common questions

How many trademark classes are there in India?

India follows the Nice Classification, which has 45 classes: Classes 1 to 34 cover goods and Classes 35 to 45 cover services.

Learn more

Can one trademark application cover more than one class?

Yes. Indian law allows a single application covering multiple classes, with the official fee payable for each class. Separate applications per class are also common.

Learn more

Is this tool's result final?

No. It gives an indicative starting point. The exact class depends on how your goods or services are described, and the Trade Marks Registry decides classification. A professional search confirms classes and conflicts.
